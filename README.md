# Cozinha São Pedro Fafá

Site institucional responsivo desenvolvido com HTML, CSS, Bootstrap 5 e JavaScript.

Esta revisão inclui correção do overflow lateral no mobile, logo recortada para melhor legibilidade, acessibilidade para movimento reduzido e dados estruturados de restaurante para SEO local.

## Estrutura

- `index.html`: conteúdo principal
- `assets/css/style.css`: identidade visual e responsividade
- `assets/js/main.js`: cardápio dinâmico, animações e galeria
- `assets/img/`: logo e imagens locais

## Como abrir

Abra `index.html` no navegador. Para publicar, envie toda a pasta mantendo a estrutura dos arquivos.

## Atualização do cardápio

Edite o objeto `menuData` no início de `assets/js/main.js`. Cada item possui `name`, `desc` e `tag`.

## Fotos

As fotografias em `assets/img/` foram fornecidas para o projeto. `hero.webp` é o fundo da abertura; `salao.webp`, `interno.webp`, `ambiente.webp` e `ambiente2.webp` apresentam os espaços; `comida.webp` e `feijoada.webp` mostram a gastronomia. Todos os arquivos foram organizados sem duplicatas e com extensões compatíveis com seu formato real.
